## Desktop migration (Decision 016) — validated by user 2026-09-04, not started

Target: **Electron wrapping an Expo Web export, Windows only.** iOS/Expo Go is **abandoned** (not kept in parallel) — `mobile/` stays the one codebase, its shipped target changes. SQLite progress starts fresh on PC, no phone-DB migration. Scheduled OS reminders are replaced by an in-app "cartes dues" check at launch. Full reasoning and the 3-way target comparison (Expo Web alone / Electron / Tauri) are in `docs/DECISIONS.md`, Decision 016. Nothing below is implemented yet — no code has been written for this initiative.

Feature-parity status (per the explicit checklist requested):

| Feature | Status | Note |
|---|---|---|
| SM-2 (vocabulaire, conjugaison, expressions, compréhension écrite) | À adapter | Engine (`sm2/`) and scheduler logic are pure TS, untouched — only the SQLite access layer changes (native Node driver via Electron's main process instead of `expo-sqlite`). |
| Decks & mots (édition `updateWord`, filtres) | À adapter | Same DB-layer swap as above; UI/logic otherwise unchanged. |
| Écoute (sous-titres + lecture vidéo segmentée) | À réécrire | Component/transport level only — the injected scripts (`NETWORK_PATCH_SCRIPT`/`CLICK_SCRIPT`/`DOM_FALLBACK_SCRIPT`) and all of `transcriptParsing.ts` are reused near-verbatim, ported from `react-native-webview` to Electron's `session.webRequest`/`executeJavaScript`. Video playback drops `react-native-youtube-iframe` for a plain `youtube.com/embed` iframe + the official IFrame Player API — simpler on desktop than on mobile. |
| Livres — parsing EPUB (`jszip`, `books/parsing.ts`) | Marche tel quel | Both are pure JS/TS with no RN import; expected to bundle and run unchanged under Expo Web. |
| Livres — import de fichier | À adapter | `expo-file-system`/picker has no web support; replaced by Electron's native `dialog.showOpenDialog` + Node `fs`. |
| Livres — traduction DeepL | À adapter | DeepL blocks direct browser `fetch` via CORS (confirmed) — the call moves into Electron's main process (Node, not subject to CORS) and reaches the renderer via IPC instead of being called directly from UI code. |
| Historique / stats / "Réinitialiser ma progression" | À adapter | DB-layer swap only, same as SM-2 above. |
| Rappels de révision | Perdu, remplacé | `mobile/src/notifications/` (queue/scheduler/categories) deleted, not ported — replaced by an in-app due-card count shown at launch (reuses `getDueCardsSplit`, just displayed instead of scheduled). |

Phases (each independently commitable, in order):

- [ ] **Phase 1 — Web smoke test.** Add `react-dom`/`react-native-web` (Expo CLI auto-installs on first `expo start --web`), boot the existing app under plain Expo Web with no Electron yet. Expect the WebView-dependent screens (Écoute, Livres translation) to break — that's fine at this phase, the goal is only to find what else breaks in the non-WebView 80% of the app before adding Electron's complexity on top.
- [ ] **Phase 2 — Electron shell + desktop SQLite.** Minimal Electron main process loading the Expo Web output; swap `expo-sqlite` for a native Node SQLite driver used from the main process, reached from the renderer via a preload/IPC bridge (required by Electron's context-isolation model — renderer code can't call Node/`fs` directly). Port `migrateDbIfNeeded` and confirm a basic read/write round-trip.
- [ ] **Phase 3 — SM-2 review flows on desktop.** Vocabulaire/conjugaison/expressions/compréhension écrite review screens working end-to-end (mouse/keyboard) once the DB layer from Phase 2 is in place.
- [ ] **Phase 4 — Decks & mots, Historique/Stats, reset.** Filters, word editing, history correction, "Réinitialiser ma progression" verified on desktop.
- [ ] **Phase 5 — Écoute rewrite.** Captions interception via Electron's `session.webRequest`/`executeJavaScript` (reusing the injected scripts and `transcriptParsing.ts`), video playback via a plain YouTube embed iframe.
- [ ] **Phase 6 — Livres rewrite.** Native file-picker import, DeepL calls proxied through the main process via IPC.
- [ ] **Phase 7 — In-app reminder.** Delete `mobile/src/notifications/`; add a due-card count check at launch.
- [ ] **Phase 8 — Packaging & docs.** Electron packaging (installer/executable) for Windows; update `CLAUDE.md`'s "Active stack" section and this file/`docs/AUDIT.md` to reflect the desktop target; full manual verification pass on the actual PC (not `tsc`/`jest`/bundle-boot only).
